# Function: pickLocale()

> **pickLocale**(`preference?`): `"en"` \| `"de"`

Picks the best supported locale from a preference: "de", "de-AT", or a whole
Accept-Language header ("de-DE,de;q=0.9,en;q=0.8"). Falls back to English.

## Parameters

### preference?

`string` \| `null`

## Returns

`"en"` \| `"de"`
